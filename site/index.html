Project overview

Stay & Shop Reservation System

A sophisticated Java SE application that automates the reservation process for a combined store and hotel. The system provides a seamless experience where guests can book rooms and shop for products all in one integrated platform.

Guest portal

Intuitive booking, account management, reservation history, and seamless profile customization

Real-time operations

Live clerk dashboard with occupancy metrics, check-ins/outs, arrivals, and automated shift management

Secure authentication

Password strength validation, email verification, sign-in audit history, and device tracking

Integrated retail

Full-featured shop with search, inventory tracking, persistent cart, and guest-only checkout

Advanced billing

Unified ledger with Stripe integration, PDF receipts, saved payment methods, and admin analytics

Admin command center

Executive KPIs, staff management, integrations dashboard, and comprehensive system controls

Smart notifications

Email and in-app alerts for reservations, charges, shop orders, and security events
